# Sarkar AI - Standalone Voice & Action Assistant Application

Welcome to **Sarkar AI**, an advanced terminal-based desktop assistant powered by the Gemini 2.5 engine, developed by Rajarshi Sarkar.

### 🚀 System Features:
* **Core Brain:** Multi-turn conversational memory with intelligent text processing.
* **System Automation:** Directly triggers local Windows applications (Google Chrome, Notepad, Calculator) upon request.
* **Music Matrix:** Intercepts song commands to automatically launch and search YouTube tracks.

### 🛡️ Secure Setup Instructions:
To run this application safely without any API key leaks, save your personal token inside your Windows system profile as an environment variable named `GEMINI_API_KEY` before starting the script.
